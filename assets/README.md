# Application icons

`hikvision-sadp.png` is the 1024 px application icon; `hikvision-sadp-128.png` and `hikvision-sadp-256.png` are scaled PNG exports for the hicolor theme. All retain an alpha channel. Keep the filenames stable so existing launchers and pinned applications continue to resolve their icon.

The white exterior of the original camera artwork was removed with the built-in image generation/editing tool on 2026-10-21. The generated result was exported at the three application sizes with alpha preserved.

Preserve exactly the dark rounded tile, red outline, red camera, signal waves, proportions and all interior artwork. No new elements, no text, no recoloring. Center the rounded tile and make it occupy approximately 90% of the square canvas (small even transparent margin), so it reads well in Ubuntu's dock. Clean antialiased edges.
